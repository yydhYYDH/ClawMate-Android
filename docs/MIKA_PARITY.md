# Mika 功能对照与验收

对照 [Mika `eb10b34`](https://github.com/wangzan101/Mika/tree/eb10b349f86654125e0db5325714e410b5431054) 的 [用户功能](https://github.com/wangzan101/Mika/blob/eb10b349f86654125e0db5325714e410b5431054/docs/features.md)、[架构](https://github.com/wangzan101/Mika/blob/eb10b349f86654125e0db5325714e410b5431054/docs/dev/architecture.md)、[模型设置](https://github.com/wangzan101/Mika/blob/eb10b349f86654125e0db5325714e410b5431054/docs/models.md) 和 Android 应用清单。验收对象为原 ClawMate 共享 APK。Mika 的 Kotlin 内核已引入，表中单列每条能力的宿主适配与验收。

| 原版能力 | 当前 ClawMate 接入 | 验收条件 |
| --- | --- | --- |
| 对话、模型循环、工具调用、取消 | 云端聊天已接原版 `AgentLoop` 与动作执行器。明确指定已安装的应用时直接进入确认，手机任务取消已在 OPPO 验收。本地聊天和 Codex 聊天尚未接入 Mika 手机执行 | 云端主屏路径、端侧和 Codex 各自从请求跑到结果，取消传递给模型和手机执行器 |
| 插话、撤回、修改、恢复、并行与子任务 | 运行时类型已引入，聊天和 Android 任务服务待接 | 原对话插话可达，未消费输入可撤回，停止后有真实进度，恢复和并行行为可观察 |
| 打开 App、读树、点按、滑动、搜索输入、翻页、查找、提取、滚轮、分享 | 按次授权的同包控件读取、部分点按、搜索框输入与滚动已接线。OPPO 已用真实云端模型读取计算器和小红书「发现」页并回传结果。通用手势、后台返回、通用文本输入、窗口事件与高级工具待迁移 | 小红书搜索页的站内热搜榜单独验收，用合成页对照通用手势、跨窗口与跨应用状态 |
| 长列表、聊天历史、成批执行 | 原版 Kotlin 工具已引入。Android 窗口适配和批量回执待验收 | 多页重叠去重、进度、停止、续跑、部分成功回执 |
| 后台屏、主屏焦点隔离、旋转、预览、接管、退出后的 App 去留 | 云端入口绑定 ClawMate 后台屏助手。OPPO 已验收计算器和小红书的独立屏启动、实时预览、主屏焦点、读取与停止回收 | 继续核对不同应用、旋转、虚拟屏接管和退出后的 App 去留 |
| 本机无线调试、USB 启动、断线恢复、自检 | ClawMate USB 助手已验证连接。Mika 配对向导、自动恢复和自检待接 | 从无配对开始，完成授权、配对、使用、重启、重连和解除 |
| 闹钟、计时器、闹钟列表、日程表单、批量写入日历 | OPPO 在无障碍关闭下通过既有云端模型验收一次性和重复闹钟、闹钟列表、计时器启动和预填日程表单。计时器标签被系统时钟替换。批量写入已接原版工具和日历提供方，专用入口及缺少写权限时的回执已真机验证 | 核对原版和 OPPO 计时器标签行为，验收授权后的批量写入和回执；继续接入在屏幕上修改时钟记录 |
| 询问与自主、登录和验证码、下单及付款接管、应用访问设置 | 内核包含原版策略，安卓当前只有按次确认和有限接管 | 逐一验证策略切换、用户退出接管、App 权限边界及高影响操作确认 |
| 内置浏览器、登录态、标签、页内调用、浏览器接管、下载上传、搜索 | 待接 Mika 的浏览器端口和 Android 页面 | 浏览器会话持久化，用户触摸能暂停任务，上传下载可核对真实文件 |
| 截图读屏、看图定位、当前主屏提问、悬浮胶囊、快捷设置 | OPPO 验收主屏任务浮窗显示应用、步数和停止入口。Mika 的图像输入与胶囊待接 | 使用合成页面验证图片来源、缩放映射、过期引用和手动接管 |
| 定时、条件触发、重启恢复、原会话交付 | ClawMate 有采集提醒。Mika 的运行调度和持久化待接 | 定时及条件任务在允许条件下执行到原会话，暂停和重启结果可区分 |
| 知识、技能文档、个人技能、记忆、画像、学习与经验回放 | 参考资源和索引已随内核编译。运行端口、持久化、管理页及回放待接 | 可查看、编辑、持久化及撤回，核对实际调用了所选知识和技能 |
| 语音输入、悬浮胶囊发送、服务商语音模型 | ClawMate 有聊天语音入口。Mika 胶囊语音和任务口径待接 | 按住说话后可编辑，从浮窗可发送，授权撤回和取消能停止录音 |
| 文件、工作区、Linux 沙箱、终端、生成文件与预览 | 内核有契约，Android 沙箱服务、原生资源和文件页面待接 | 按会话隔离，能运行并交付实际文件，验证权限、取消和空间清理 |
| CLI、MCP、USB、局域网与远程连接、电脑工作台和运行导出 | 有既有 Codex 桥接。Mika 的电脑端协议和 Codex 向手机委托待接 | 核对认证、重复请求、取消、会话归属和重连后的结果 |
| 模型配置、主模型和视觉模型、决策模型、登录、额度、代理、费用和上下文 | 复用当前云端配置。其他服务商、账号登录、可用额度、计费及原版端口待接 | 各协议分别验证流式输出、工具调用、图片能力、登录存续和错误提示 |
| 来电及通知感知、微信接入、其他平台插件 | 对应 Android 服务和界面待接 | 分别验收安装能力、系统授权、撤回及数据流 |
| 运行记录、步骤证据、回看、导出、诊断、版本更新 | 云端聊天实时显示手机任务状态和步骤，并支持在同一条回复里回看进度。Mika 运行记录和诊断功能待接 | 实际步骤可回看并导出，失败可定位，发布包升级能保留配置 |

图编辑与既有采集工作流继续按独立产品入口回归。本表的接入状态依照构建、受控测试、真机和实际服务分别记录，详细证据见 [迁移日志](../MIGRATION_STATUS.md)。接续代码入口与复测见 [迁移交接](MIGRATION_HANDOFF.md)。
