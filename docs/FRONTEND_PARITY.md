# 共享前端与鸿蒙页面对齐

参考提交：`cd69b68bf16b9ed352be5073939eb24d042de583`。上游只读，所有编译输入均检查 Git blob。
页面以原 ArkTS 实现为主，Android 差异保留在 `shared-frontend/adapters/` 和可审查的准备脚本中。

| 范围 | 对齐方式 | 仍存在的边界 |
| --- | --- | --- |
| 主导航 | 使用原五个入口、标签和图标；从原 FloatingMainTabs 提取 64vp 高、20vp 侧距、12vp 底距；原 Index 的图标/字体/配色样式随锁定输入提取 | Android 用标准 ArkUI 胶囊与组件模糊近似；没有 HDS 沉浸材质或温控光效 |
| 页面与固定顶栏 | 首页、汇总、聊天、任务、设置及二级内容沿用源码；保留原 56vp 顶栏和内容间距 | FrostedPage 使用原标准 ArkUI 回退；字体栅格与系统导航转场不同 |
| 主题 | 原 AppTheme 与日/夜间资源；Android 系统主题通过平台状态同步，系统栏由宿主管理 | 仍须在目标厂商系统回归 |
| 聊天 | 原消息、思考、抽屉、头像、语音与附件控件；Android统一窗口缩放。ASR/相册/相机、当前回合图片发送、query_events已接通 | 真人ASR、真实视觉效果/相机实拍待验收；只执行只读记忆工具，其他模型工具拒绝 |
| 语音朗读 | 原消息按钮调用旧版抽取的本机 TTS；真实回调更新头像/状态，支持停止与按文本重播 | 设备须提供中文引擎；无音频文件时不伪造缓存 URI |
| 图库与 OCR | 原图库布局、分析/检索/问答协议；仅将 OCR 调用改为原图 URI → 共用 Android 引擎 | 真实云模型及完整私人图库流程未验收；HDC 受限 |
| 首页弹层 | 原分身生成、历史、版本、推荐/任务详情；补齐 Android 返回事件 | 真实分身生成、照片参考上传仍未验收 |
| 引导、工作流、详情 | 原四页引导/插图、图与 JSON 编辑、文件查看、详情页继续共用 | 不能用相同源码代替实际交互与两端截图验收 |

共享源码不代表像素一致：HDS材质、系统字体和原生动画仍需鸿蒙同状态截图/录屏对照。
Android统一管理键盘可用窗口；动态主题切换后的UIAutomator节点刷新及TalkBack仍有验收边界。
功能进度、实际验证及阶段修正统一见[迁移日志](../MIGRATION_STATUS.md)。
